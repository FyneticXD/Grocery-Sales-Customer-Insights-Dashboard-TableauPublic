# Grocery Sales & Customer Insights Dashboard - Tableau

## 📊 Deskripsi Proyek

Proyek ini merupakan portofolio visualisasi data menggunakan **Tableau Public**. Dashboard dirancang untuk menganalisis performa brand, kategori produk, serta hubungan antara **ratings** dan **reviews** pada dataset grocery. Tujuan utama proyek ini adalah menyajikan insight bisnis secara interaktif untuk mendukung pengambilan keputusan berbasis data.

## 📂 Dataset

Dataset yang digunakan (`GroceryDataset.csv`) berisi data produk grocery beserta informasi kategori, sub kategori, brand, rating, dan jumlah ulasan pelanggan.

Fitur utama dalam dataset meliputi:

* **Brand**: Nama merek produk grocery.
* **Category & Sub Category**: Klasifikasi produk berdasarkan kategori dan sub kategori.
* **Ratings**: Penilaian pelanggan terhadap produk.
* **Reviews**: Jumlah ulasan yang diberikan pelanggan.

## 💡 Fitur Dashboard & Wawasan Utama

Dashboard Tableau (`Grocery Dataset TableauPublic.twbx`) mencakup analisis berikut:

* **Brand Total**: Visualisasi Bubble Chart untuk membandingkan kontribusi setiap brand.
* **Ratings & Reviews**: Scatter Plot untuk melihat hubungan antara jumlah ulasan dan sub kategori produk.
* **Category Analysis**: Membantu mengidentifikasi kategori dengan performa terbaik.
* **Interactive Dashboard**: Dashboard interaktif yang memudahkan eksplorasi data.

## 🛠️ Teknologi yang Digunakan

* **Alat Bantu Utama**: Tableau Public
* **Pemrosesan Data**: Microsoft Excel
* **Sumber Data**: File CSV

## 🚀 Cara Menjalankan Proyek

1. Pastikan Tableau Public atau Tableau Desktop telah terinstal.
2. Clone repository ini atau unduh seluruh file.
3. Buka file Tableau Workbook (`.twb` atau `.twbx`).
4. Jika diperlukan, arahkan ulang sumber data ke file `GroceryDataset.csv`.
5. Dashboard siap digunakan untuk eksplorasi data.
